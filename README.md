# BizBook KZ 💼

Бухгалтерия для ИП и ТОО в Казахстане.

---

## 🚀 Как опубликовать за 10 минут (бесплатно)

### Способ 1 — Через GitHub + Vercel (рекомендуется)

**Шаг 1: Загрузи код на GitHub**
1. Зайди на [github.com](https://github.com) → зарегистрируйся (бесплатно)
2. Нажми **"New repository"** → назови `bizbook-kz` → Create
3. Нажми **"uploading an existing file"**
4. Перетащи ВСЕ файлы этой папки → нажми **Commit changes**

**Шаг 2: Опубликуй на Vercel**
1. Зайди на [vercel.com](https://vercel.com) → войди через GitHub
2. Нажми **"Add New Project"**
3. Выбери репозиторий `bizbook-kz`
4. Framework: **Vite** (выберется автоматически)
5. Нажми **Deploy** → через 2 минуты получишь ссылку!

**Результат:** `https://bizbook-kz.vercel.app` (или своё имя)

---

### Способ 2 — Напрямую через Vercel CLI

```bash
npm install -g vercel
vercel login
vercel --prod
```

## 📱 Как установить на телефон (иконка на экране)

### На iPhone (iOS):
1. Открой ссылку в **Safari** (не Chrome!)
2. Нажми кнопку **Поделиться** (квадрат со стрелкой вверх)
3. Прокрути вниз → **"На экран «Домой»"**
4. Нажми **Добавить** → иконка BizBook KZ появится на экране!

### На Android:
1. Открой ссылку в **Chrome**
2. Нажми **⋮** (три точки) → **"Добавить на главный экран"**
3. Нажми **Добавить** → готово!
